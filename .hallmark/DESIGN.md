# Typhoon Lab: design record (v0.2, worldwide world)

Hallmark `redesign` inside the existing implementation boundaries; the user explicitly authorised the single-page layout change, so there was no approval round. Silent inference: audience = people exploring a fictional live weather world on desktop or phone · use = drop weather conditions on the map and watch storms form and grow · tone = technical, austere.

- Genre: atmospheric. Macrostructure: **full-bleed instrument map**. The map is the whole viewport (100dvh, also on phones); everything else floats over it. The old three-column workbench, dock, left tools and stacked mobile page are gone.
- Theme unchanged: custom "Observatory Night" (dark navy sea, pale coast, amber for the single active thing). All colour, type, spacing and motion values still come from `tokens.css`; JS reads the same tokens.
- Layout: top-left brand + help; clock/play/speed/reset beside it on ≥48 rem (a row above the palette on phones, play button icon-only to fit 320 px); layer tabs and a compact legend under the brand; zoom and the sidebar toggle at the top right; weather palette bottom centre (full width on phones); hint/toast/readout stack above it. The only panel is the right sidebar (Storms · World · News · Replay), open by default on ≥70 rem, collapsed on smaller screens. From 48 rem it is an in-flow column beside the map (the map stage shrinks to the remaining width and every floating control is positioned against the stage); on phones it overlays the map.
- Weather palette: ten pointer-event draggable icons (mouse, pen, touch; `touch-action: none`, pointer capture on the button so the map cannot pan while dragging, ghost icon lifted above a finger). A press without movement arms the tool (click or tap the map to place, Esc to put away). Keyboard: Tab to a palette button, Enter arms it, focus the map, arrow keys move the target (Shift ×5, Alt ¼°), Enter places. The World tab places by exact coordinates. One row of ten on ≥48 rem, 5 × 2 below; keys 1–9 and 0 arm them in order.
- Camera and freeze: the default map is a 3D globe (drag rotates, wheel and pinch zoom); the flat Equal Earth map is the fallback and a settings toggle (`?map=flat|globe`, remembered in `localStorage['typhoon-lab-map-mode']`). The flat world repeats horizontally, so the dateline is never a seam. Pan, pinch and wheel set `data-interacting="true"` on `map-stage`: the weather picture (field, particles, animation clock) is frozen while the camera still redraws; the worker keeps running, and on release the latest state is shown. `data-rendered-tick` is the tick being drawn.
- Honest copy: no budgets, costs, rankings or end screen. News is "Fictional breaking news"; forecast cones are labelled approximate; population is "fictional demo value, 2025"; impact "is not a casualty count or a financial loss". Forming patches show percent of the genesis threshold, not elapsed hours.
- Storm glyph: counter-clockwise spiral in the north, clockwise in the south; its size grows with wind and with the storm's age, so a young depression reads small. Candidate patches are dashed rings with a percent label. Tool glyphs show the same rotation rules.
- Motion: opacity and transform only; reduced motion freezes particles into static streaks and stops overlay animation.

## Map architecture

- Camera: `MapCamera` (`camera.ts`) is implemented by `FlatView` (`view.ts`, Equal Earth) and `GlobeView` (`globe-view.ts`, orthographic sphere with an inverse-rotation drag solve). All drawing goes through `projectZ(lon, lat) → [x, y, z]` where z is visibility (flat is always 1; globe z <= 0 is the far side). `MapRenderer.view` returns the active camera and must be read each time; `setMode` swaps it and carries the view over. Canvas 2D is flat only.
- Flat base layer: Three.js WebGL2 (orthographic camera; 180×90 field DataTexture with repeat wrap on S; Shape land mesh; particle streak mesh), tiled ×3 around the dateline. Globe base layer: a rotated sea sphere, triangulated land, a field sphere and an atmosphere ring, with wind streaks in a second screen-space pass. Fallback: Canvas 2D with the flat layers (one padding column on each side of the field, tiles clipped to avoid seams). A transparent Canvas 2D overlay draws graticule, coastline, isobars, tracks, forecast cones, effects, patches, storms, cities and the placement preview.
- Ground circles are latitude-aware ellipses on the flat map (`kmToWorld`, cosine floor shared with the simulation) and great-circle circles on the globe; particle velocity is converted so on-screen wind direction equals ground direction, and on-screen speed is constant across zoom levels.
- `window.__typhoonLab`: `state` (newest worker state), `mapView` (active camera with `lonLatToPx` / `pxToLonLat` / `centerLonLat`), `mapMode` (`'globe'` or `'flat'`), `playing`, `renderedTick`, `interacting`, `renderer`.
